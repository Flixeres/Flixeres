## 📂 Проекты (гибридные)

| Проект | Описание | Стек |
|--------|----------|------|
| 🧙 **Lua2Net** | Экзекьютор отправляет telemetry через HTTP на твой сервер | Lua + Python + FastAPI |
| 🔌 **MikroLua** | Скрипты для MikroTik через Lua (RouterOS встроенный Lua) | Lua + RouterOS CLI |
| 📡 **NetBackup** | Автоматический бэкап конфигов роутеров в Git + Telegram-бот | Python + Netmiko + Git + Aiogram |
| 🎮 **ESP Over VPN** | ESP-чит, который показывает через WebSocket координаты на карте в Grafana | Lua + C++ + WebSocket + Grafana |
| 🧪 **EVE-NG + Roblox** | Эмуляция сети из 5 роутеров + запуск Lua-экзекьютора в изолированной VM | EVE-NG + Python + VMware |
| 🔐 **Lua Obfuscator API** | HTTP API для обфускации Lua-скриптов (поднимается на Cisco CSR1000v в Docker) | Lua + Python + Flask + Docker + Cisco |
